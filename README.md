# テールくんのカレー

牛テールカレー専門店「テールくんのカレー」の紹介ページ(静的HTML)。

## 構成
- 単一の `index.html`(CSS はページ内に記述、外部依存は Google Fonts のみ)
- Vercel でホスティング

## 更新方法
1. このリポジトリを clone
2. `index.html` を編集
3. `main` に push すると Vercel が自動で再デプロイ
